# 验收证据目录（docs/evidence）

存放对照正式需求 / 验收口径跑测后的证据：截图、探针 JSON、验收记录 Markdown 等。

## 约定

1. **一条变更 / 一轮验收**尽量一个主题目录或一组带统一前缀的文件（例：`主题_验收记录_YYYY-MM-DD.md` + 相关截图）。
2. 验收记录须写明：对照的正式文档路径、勾选的验收条文编号（若有）、结论（通过 / 不通过 / 非阻断）、证据文件清单。
3. 变更账本关单时，在对应条目「备注」中写上本目录下的证据路径。
4. 不在此目录存放密钥、账号凭证或标注机密的业务数据。

## 与变更账本

正式口径变更先记入 `docs/变更账本.md`，再改正式文档；验收通过后由需求角色关账，并在账本备注中引用本目录证据。
