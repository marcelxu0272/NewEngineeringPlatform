## 已实现

- 两个目录项从占位升级为真实报告列表；按报告期降序展示标题、摘要、页数、大小、组织、时间。
- 标题/报告期/摘要搜索、报告期筛选、空态与清空筛选。
- 壳年度与组织筛选作用于列表：全部板块可见所有归属，具体板块仅匹配自身归属；此处为内容筛选，不是权限控制。
- 上传 PDF：填写标题、报告期、组织和摘要，支持最大 20 MB、1–1000 页、未加密 PDF；文件内容验证后保存，失败反馈保留表单供重试。
- 报告元数据和原始文件二进制存入共用 `data/platform.db` 的 `pdf_reports` 表，不新增平行数据库。刷新后可继续查看。
- 每类别两份两页合成示例（2026-09 / 2026-10），界面及 PDF 明确标注演示内容，不包含真实经营数据或指标结论。
- 阅读弹窗：两列字段信息、多页连续滚动、适宽与缩放、下载、失败与重试、键盘关闭及返回焦点。
- PDF.js worker、CMap 与标准字体从本机依赖提供，无外部 CDN。
