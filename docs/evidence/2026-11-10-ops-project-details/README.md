# 年度KPI与项目明细下探 · 实现自验

日期：2026-11-10。依据：当前用户要求及所附项目明细弹窗截图；变更账本同日“年度KPI名称与六项项目明细下探”条。

## 已实现

- 顶部主卡名称为：年度新签合同额、年度完成合同额、年度完成开票额、年度完成回款额。保持原金额、目标、当月/上月新增、子目标与12段轨道计算。
- 四个KPI、WIP、应收账款六个下探统一展示项目编号、项目名称、甲方名称、项目经理、负责人、管理归属、业务类型、日期、金额（元）。仅年度新签合同额最后增加“类型”列，包含新签/变更。
- 管理归属下拉、项目编号/名称/项目经理/甲方名称即时搜索、默认每页10行分页（按用户后续要求由20行调整）、空态及BOM UTF-8 CSV导出。导出完整筛选结果，不限当前页。
- 明细为独立的确定性演示项目/甲方/人员，未抄录截图真实记录。按当前主卡已展示金额分摊，以整数分保存计算；明细合计精确对应主卡万元数值×10000元。
- 随壳级组织过滤明细范围，不能从叶子板块窗口扩到其他板块；窗口打开时切组织也刷新明细。主题变化保留弹窗及当前查询。
- 窗口适配iframe可用宽高；窄窗表格内部横向滚动，新签类型列固定右侧；长文本title可查看完整内容。
