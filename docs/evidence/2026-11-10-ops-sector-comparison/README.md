# 月度明细板块比较验收记录

日期：2026-11-10。对应变更账本“月度明细板块比较”及当前用户批准方案，维持实现中供需求角色收口。

## 实现

运营看板11项金额指标月度明细，在全部板块时提供比较入口。2—3个板块共用原月度整数分矩阵，支持搜索、多选上限、已选移除、当月/累计切换、余额口径、三折线与全年表、逐板块汇总和BOM CSV。

`overview/comparison.js`独立维护模型投影、选择交互与比较图表；原`monthly.js`接入，沿用相同图表销毁入口。会话内共用所选板块；新弹窗默认普通明细。项目Tab可恢复管理归属、搜索与分页。具体板块下退出比较并隐藏入口；返回全部板块仍可使用保留的选择。

不改变主卡或其他看板，不新增API、数据库、依赖与持久化。
