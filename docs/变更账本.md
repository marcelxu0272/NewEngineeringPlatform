# 变更账本

本文件是工程平台（`26_engineering-platform`）的**唯一需求变更账本**：任何对正式需求 / 验收标准 / 已确认范围的改动，须先在此追加一条记录，再改对应文档。

> 路径约定（相对本仓）：账本为 `docs/变更账本.md`；验收证据为 `docs/evidence/`；既有正式/设计稿仍在 `docs/需求文档/`、`docs/plans/`、`docs/DESIGN.md`、`docs/DASHBOARD.md`、`docs/LIST_FORM.md` 等，**引用不改口径**，直至用户确认新口径后再落文。
>
> 对齐看板中心流程：看板中心账本在 `需求与验收标准/变更记录.md`、证据在 `docs/evidence/`。工程平台正式材料已落在 `docs/` 下，故账本与证据同置 `docs/`，避免再开平行顶层目录。

## 协作约定（硬约束）

- 多人 / 多 Agent **异步**协作，不会同时改同一文件；动手前先读本文件与相关正式文档最新状态。
- **只有**需求角色 Agent（或用户明确授权之人）可改正式需求 / 验收口径；其他角色发现问题只可提出，不得直接改口径。
- 每条变更须写清：日期、发起人、摘要、影响范围、对应文档路径、状态（提议 / 已确认 / 已落地）。
- 与其他 Agent 沟通或派活时，**必须主动提及**本文件及与本任务相关的未结变更。
