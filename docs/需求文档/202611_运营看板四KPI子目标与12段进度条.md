## 业务规则

### 对象

Board 树顶「运营看板」顶部四张主卡，名称与现行文案保持：

| 主 KPI | 现行右上角新增文案 |
| --- | --- |
| 新签合同额 | 当月新增 |
| 完成合同额 | 上月新增 |
| 完成开票额 | 当月新增 |
| 完成回款额 | 当月新增 |

金额单位是万元。每张主卡包含三行子目标，顺序为 EPC、PMC、设计及咨询。每行有类别、完成额/目标额、进度条、百分比。

组织用现有壳级组织板块。共 13 个：全部板块，以及 SAS170 PMC板块、SAS610 咨询板块、SAS680 数字技术板块、SAS650 新材料板块、SAS710 生命科学板块、SAS690 COII板块、SAS720 模块化板块、SAS670 供应链板块、SAS520 金山中心、SAS560 沈阳中心、SAS550 惠湛中心、SAS530 银川中心。每个组织都能看到这四张卡和这三行。本次不新增组织，也不把公司级 EPC 加进下拉。

SAS170 PMC板块是组织。子目标里的 PMC 是业务类型。同一张卡在该组织下仍然列出 EPC、PMC、设计及咨询 三行。两个 PMC 不合并、不互相替代。

### 合计

对当前选中的每一个组织、每一张主卡：

- 三行完成额之和 = 该卡主完成额
- 三行目标额之和 = 该卡主目标额

比较的是落到最小显示单位之后的金额。千分位逗号只是写法，不参加相加。三个百分比的显示值之和不必等于主卡百分比的显示值。百分比不回写成金额。

### 最小单位与余数

展示单位是万元，保留 2 位小数，并使用千分位。最小显示单位是 **0.01 万元**。0.01 万元等于 100 元。分配只走 0.01 万元这一格，账不落到 1 元，也不落到 0.01 元。

1. 分配基准是该组织、该 KPI 主卡最终展示出来的完成额和目标额。主卡内部若还有未展示的更长尾数，不参与分配。
2. 把展示金额换成最小单位整数：2 位小数的万元金额 × 100。例：展示 1.00 万元 = 100 个最小单位。
3. 完成额和目标额分开拆。余数不从完成额挪到目标额。
4. 三项演示权重都是正数，按有理数做相对比例。每类的精确值是「主卡最小单位整数 × 该类权重 / 权重和」。先取这个商的整数部分。余数个数等于主卡整数减去三类整数部分之和，只可能是 0、1 或 2。按小数部分从大到小排一次序，小数部分相同则按 EPC、PMC、设计及咨询。余数有几个，就给排在前面的几类各加 1 个最小单位。同一类最多加 1 个。谁拿到余数，用精确分数判断，不用二进制浮点的近似值。
5. 三类整数之和等于主卡整数。再除以 100，写成 2 位小数和千分位。因此用户看见的三类之和等于用户看见的主卡金额，显示舍入不会把合计漂掉 0.01 万元。

验算例只用于核对算法，不是业务数据，也不是演示权重的规定值。主完成额展示 1.00 万元，测试权重 1:1:1。每类 100/3，整数部分各 33，余数 1。小数部分相同，余数给 EPC。展示为 EPC 0.34、PMC 0.33、设计及咨询 0.33，和为 1.00。

### 演示权重

拆分权重是显式演示配置，旁边标明「仅演示、非业务默认」。本文不规定三项的具体数值，也不把任何比例写成业务默认值。

现行演示里的「设计咨询 / 项目管理 / 工程服务」及其权重，不是这三类，不拿来当映射。仓内其它页面、种子数据里的另一套 EPC / PMC / 设计及咨询静态数，也不是本次演示拆分的来源。

### 比例、轨道与超额

比例用分配之后的金额计算：完成额的最小单位整数 ÷ 目标额的最小单位整数。这个商在还没有做百分比舍入时就确定。进度条宽度使用这个未舍入的比例，宽度上限为轨道的 100%。文字上的百分比只做展示，展示结果不反推金额，也不反推条宽。

主条和子条的轨道都分成视觉上等宽的 12 段。段是刻度。填充连续，不停在整段边界上，也不按 1/12 四舍五入。

超过 100% 时，填充停在轨道尽头，百分比文字显示真实比例。

进度百分比的文字按四舍五入保留 2 位小数。主条旁的百分比，以及主卡上表示同一比例的「占总目标」，使用这同一套展示，避免同一比例两处位数不同。词语「占总目标」保留。当月新增、上月新增，以及这两处旁边的「占目标」，维持现行文案和现行 1 位小数；那是另一套比例，本次不拆到子行。

颜色沿用当前主题。参考图里的蓝色不写成色值规范。

测试例只检验轨道，不进入演示主数据：

### 异常

目标额的最小单位整数为 0 时不做除法。百分比文字为「—」，并标明「无目标」。12 段轨道仍显示，填充宽度为 0。不用满条代替「无目标」，也不把「—」写成 0% 或 0.00%。主目标展示为 0.00 时，三行目标额都是 0.00，三行都按无目标处理。

缺失与有效完成额 0 分开：

- 有效完成额 0：目标额大于 0，完成额的最小单位整数为 0。展示 0.00 与对应目标额，百分比文字显示 0.00%，填充宽度为 0。不标「缺失」，不标「无目标」。
- 缺失：这一类没有演示记录。该行仍保留类别名。完成额、目标额、百分比都显示「—」。不标「无目标」，除非目标额本身已知为 0。轨道不填充。不得把缺失补成 0.00 去凑主卡合计。该组织该 KPI 只要有一行缺失，合计验收就不通过。

演示数据要满足合计，每个组织、每个 KPI 的三类记录都要有。缺失规则用于记录不齐的时候，避免把洞显示成 0。

## 数据关系

一张主卡在一个当前组织下有一个主完成额和一个主目标额。二者都是该卡最终展示的万元金额，2 位小数。

每个组织、每个 KPI 有三行：EPC、PMC、设计及咨询。每行有完成额和目标额，由对应的主展示金额按演示权重拆成最小单位整数后再写回 2 位小数。

关系如下：

- 三行完成额的最小单位整数之和 = 主完成额的最小单位整数。
- 三行目标额的最小单位整数之和 = 主目标额的最小单位整数。
- 行比例 = 该行完成额整数 ÷ 该行目标额整数。目标额整数为 0 时没有比例。
- 主条比例 = 主完成额整数 ÷ 主目标额整数。目标额整数为 0 时没有比例。
- 条宽 = 未舍入比例对应的宽度，并且不超过轨道全长。
- 百分比文字是比例的展示。它不写回整数，也不写回条宽。
- 当月新增、上月新增只属于主卡，不按三行拆分。
- 组织维度与业务类型维度独立。12 个叶子和「全部板块」各自使用自己的主卡展示金额再拆三行。「全部板块」的三行合计对齐的是「全部板块」这张主卡的展示金额。本文不另加一条「12 个叶子的业务类型必须再加总成全部」的业务规则。

演示数据的现有生成方式可以继续产生主卡展示金额。子目标从展示金额往下拆。仓内已观察到的演示差异，例如全部板块部门权重和不是 1、新增额所用系数与主金额系数不同、旧页面另有一套静态子目标、种子数据与另一页面不一致，都只是现有演示实现彼此不同。它们不是业务事实，本文不把它们收成口径，也不要求顺便改掉。

显示与计算的一致性：

- 金额等式只在最小单位整数上成立，所以 2 位展示加总与主卡展示一致。
- 百分比各自展示后，显示出来的百分数相加可以与主卡百分数不同。这不破坏金额等式。
- 缺失不用 0 进入等式。有缺失时不算合计通过。
- 目标额为 0 时没有百分数，轨道不填充。
- 115.68% 这种测试例允许「条宽已满」与「文字大于 100%」同时成立。
