# 202611_组织图板块跳转Board筛选

> AI 更新摘要（2026-11-03）：组织图一级页可点击 12 个板块/中心叶子，跳转运营看板 Board 并带上对应该叶子的壳级「组织板块」筛选；Board 主区 header 随选中态显示「SAS + 标准名」，全部板块时定稿为「Board」；命名以 wood-groupname 为准；不含公司级 EPC。

## 业务规则

1. 用户从运营看板202610 **组织图一级页**（`org-entry.html`）点击某一 **板块/中心叶子**，进入 **Board**（`/operations-dashboard-202610/board`），且壳级「组织板块」选中态等价于手动在下拉里选中该叶子。
2. 组织命名与负责人一律以技能 **wood-groupname** 为准（标准名；展示可带 SAS 码，与壳 `UNIT_OPTIONS` 一致）。
3. **可点击跳转的叶子**仅下表 12 项（**不含「公司级 EPC」**）：

4. 壳下拉展示文案与「壳级组织板块换成真实叶子」条对齐，形如 `SAS170 PMC板块`（SAS + 空格 + 标准名）；`unit` 传值与 `UNIT_OPTIONS` **同一套键**，本条不另造第三套编码。
5. **Board 主区 header**（壳内原写死「Board」的标题位）**随「组织板块」选中态变化**，不写死：
   - 选中表中任一叶子 → header = 该选项展示文案，例 **`SAS170 PMC板块`**。
   - 选中 **「全部板块」** → header 定稿为 **`Board`**（产品页名；不用「全部板块」作 header）。
   - 组织图叶子跳转进入、以及在 Board 内改下拉，两条路径下 header 与选中态一致；切换后即时更新。
6. **非叶子**（项目群、公司级 EPC、职能部门/委员会/专业室、董事会等）：
   - **董事会 / Board**：保持已落地行为 → 进入 `/board` 默认运营看板（组织板块为「全部板块」或不强制改写；header=`Board`）。
   - **项目群、公司级 EPC、其它非 12 叶子节点**：默认 **不跳转 Board**（可仅图内展开/高亮或无链接）；**不得**误跳到某一叶子筛选。
7. 进入 Board 后：默认落在看板目录「运营看板」节点；壳筛选条「组织板块」= 该叶子；iframe 收到对应 `unit`（与壳手动选择同一路径）；header 为该叶子 SAS+标准名。
