# 运营看板改版：Board 内树导航 + 统一双列 + 主题出 iframe

Status: accepted（grill 收口 t45u）


澄清（t65u / grill-with-docs）后拍板：取消「所有东西放一页」的限制后，不另起顶栏导航体系，而在 Board 内容区左侧用看板目录切换节点；所有节点右侧统一双列栅格；主题放在 Next 壳全局 header（iframe 外），避免每个看板 HTML 各自一套主题控件。

## Considered Options

- **A. catalog 多入口 / 多顶栏路由**：每个看板独立全屏页。否决——用户要「一棵树整合很多看板」，且组织图 Board 仍进同一 `/board`。
- **B. 仅运营看板双列，其他节点原样嵌入**。否决——用户明确所有树节点统一双列栅格。
- **C. 主题仍留在各 iframe 内容顶栏**。否决——无法对整棵树全局生效，且与「内容顶栏只留下拉」冲突。

## Consequences

- 实现上 Board 页成为壳内导航中枢；占位节点不新开路由。
- 现有 `index.html` 顶栏与模块栅格需按口径改造；其他节点先共用占位壳。
- 组织图一级入口与 `/org-chart` 行为保持不变。
