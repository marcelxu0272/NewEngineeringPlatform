# 交付保障行动项配置系统

一个专业的交付保障行动项配置管理系统，支持通过可视化拖拽方式配置项目各阶段的保障行动项，提供完整的审批流程、版本管理和状态跟踪功能。

> 📖 操作手册：详见《[docs/操作手册.md](docs/操作手册.md)》

## ✨ 系统特性

- **可视化配置**: 支持拖拽式配置，直观易用
- **审批流程**: 完整的提交-审批-通过/驳回流程
- **版本管理**: 支持多版本配置，可查看历史版本
- **状态跟踪**: 实时跟踪行动项执行状态
- **文件管理**: 支持标准文件上传和在线预览
- **审批日志**: 完整的审批历史记录
- **非破坏性操作**: 支持配置项禁用/启用，避免数据丢失风险

## 🔄 业务流程

### 1. 配置阶段 (Configuring)
- **左侧菜单**: 显示可用的保障行动项列表
- **右侧区域**: 三个项目阶段的配置区域
- **操作方式**: 通过拖拽将行动项添加到对应阶段
- **配置要求**: 每个行动项必须设置计划时间
- **提交条件**: 所有配置项都设置计划时间后才能提交审批

### 2. 审批阶段 (Pending)
- **审批人员**: 可查看配置详情
- **审批操作**: 
  - 通过审批 - 配置生效
  - 驳回审批 - 返回配置阶段，需填写驳回原因
- **版本管理**: 审批后自动生成版本记录

### 3. 执行阶段 (Approved)
- **布局切换**: 界面切换为三栏展示布局
- **状态管理**: 
  - 进行中 (Progress)
  - 已完成 (Completed) 
  - 已终止 (Terminated)
- **文件管理**: 支持上传相关执行文件
- **进度跟踪**: 实时显示各阶段执行统计

## 📋 使用说明

### 配置操作流程

1. **管理配置项**
   ```
   点击左侧配置菜单的齿轮图标 → 进入管理界面
   - 添加新配置项：填写名称、标签、上传标准文件（仅支持PDF格式）
   - 编辑现有配置项：点击配置项进行修改
   - 禁用/启用配置项：点击禁用/启用按钮切换状态
   - 状态过滤：选择查看全部、已启用或已禁用的配置项
   ```

2. **配置项目阶段**
   ```
   从左侧拖拽配置项 → 放置到右侧对应阶段
   - 支持同一配置项多次添加（显示序号 #1, #2...）
   - 点击配置项设置详细信息（计划时间必填）
   - 悬停显示删除按钮，可移除不需要的配置项
   ```

3. **提交审批**
   ```
   完成配置 → 点击"提交配置" → 进入审批状态
   - 系统检查：所有配置项必须设置计划时间
   - 提交后不能修改，等待审批结果
   ```

4. **审批处理**
   ```
   审批人员查看配置 → 选择通过或驳回
   - 通过：配置生效，进入执行阶段
   - 驳回：填写驳回原因，返回配置阶段
   ```

5. **执行跟踪**
   ```
   审批通过后 → 进入执行视图
   - 查看各阶段配置项及状态
   - 更新行动项执行状态
   - 上传相关执行文件
   - 标记完成或终止状态
   ```

### 🔄 配置项状态管理

**禁用/启用功能特性：**
- **非破坏性操作**: 禁用配置项不会永久删除数据，随时可恢复
- **智能移除**: 禁用配置项时，自动从所有项目阶段中移除
- **状态保护**: 只有已启用的配置项才能拖拽到项目阶段
- **可视化标识**: 配置项卡片清晰显示启用/禁用状态

**操作说明：**
```
管理界面操作：
1. 查看状态：配置项卡片右下角显示"已启用"或"已禁用"标签
2. 切换状态：
   - 启用状态：显示红色关闭图标，点击禁用
   - 禁用状态：显示绿色开启图标，点击启用
3. 状态过滤：下拉选择"全部"、"已启用"或"已禁用"
4. 搜索配合：支持在特定状态下进行关键词搜索

配置界面限制：
- 左侧菜单：仅显示已启用的配置项
- 拖拽保护：禁用的配置项无法拖拽到项目阶段
- 状态同步：禁用配置项时会从所有阶段中自动移除
```

**使用建议：**
- **临时不需要**: 对于当前项目不需要但后续可能使用的配置项，选择禁用而非删除
- **批量管理**: 利用状态过滤功能批量查看和管理同状态的配置项
- **数据安全**: 禁用功能避免了误删除导致的数据丢失风险

### 📄 标准文件管理

**文件格式限制：**
- **仅支持PDF格式**: 系统只允许上传PDF格式的标准文件
- **文件大小限制**: 单个文件大小不得超过10MB
- **文件用途**: 用于上传项目标准文档、规范文件、参考资料等

**功能特性：**
- **在线预览**: PDF文档支持在浏览器中直接预览
- **工具栏操作**: 支持缩放、翻页、搜索等标准PDF操作
- **文件下载**: 支持下载PDF文件到本地
- **错误处理**: 文件损坏或格式错误时提供友好提示
- **文件验证**: 自动验证文件格式和大小限制

### 📊 状态说明

**配置项执行状态：**
- **进行中** (Progress): 蓝色边框，默认状态
- **已完成** (Completed): 绿色边框，显示完成时间
- **已终止** (Terminated): 红色边框，显示终止时间

**配置项管理状态：**
- **已启用** (Enabled): 绿色标签，可拖拽到项目阶段使用
- **已禁用** (Disabled): 红色标签，隐藏在配置界面，无法拖拽使用

**系统工作流状态：**
- **配置中** (Configuring): 可进行配置和修改
- **审批中** (Pending): 等待审批，配置锁定
- **已通过** (Approved): 审批通过，进入执行跟踪

## ⚠️ 注意事项

- **数据存储**: 数据存储在浏览器本地，清除浏览器数据会丢失配置
- **单用户使用**: 当前版本设计为单用户本地使用
- **浏览器兼容**: 建议使用 Chrome、Firefox、Safari 等现代浏览器
- **配置项管理**: 系统采用禁用/启用机制代替删除，确保数据安全。如需完全清理数据，请使用"重新开始"功能
