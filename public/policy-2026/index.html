一、2026 考核机制：三大体系
利润中心

共赢合伙机制

项目交付 / 业务板块 — 绑定目标，收益与风险对等

  • 板块/中心与公司共享年度利润贡献
  • 共享伙伴：项目群/板块/中心负责人、PM 及以上
  • 核算基准：开票收入 R（含内部收入，剔税）
  • 共享伙伴岗位工资年内暂缓，年底按 P 发放
成本中心

成本中心考核

五大专业室 — 不考核利润，重点控制成本与效率

  • 工艺设备、配管、仪电、土建、项目管理服务
  • 可分配奖金 B = 内部收入 N − 实际成本 C
  • B > 0 可分配；室主任亏损时无奖金
  • 工程师个人盈利可保留奖金资格
职能部门

职能部门考核

五大职能部门 + 技术委员会 — KPI 综合评定

  • 奖金总额 = ∑(个人奖金基数 × 部门综合 KPI)
  • KPI 由 P&L、专业室、职能部门综合评定
  • 公司 EBIT > 0 才可分配奖金
  • 公司 EBIT ≤ 0 全部门无奖金

二、共赢合伙机制详解
核算公式
利润贡献值
P = R − 年度总实际发生成本 − OH
R：年度开票收入（含内部收入，剔税）｜OH：公司管理费
可分配奖金
B = P × X%
X%：利润共享比例，按开票达标率 Q 梯级确定
开票达标率
Q = 实际开票 / 开票指标
Q 决定共享比例梯级（35% / 实际 / 45%）
共享比例梯级
开票达标率 Q含义共享比例 X%
Q ≤ 0.875 未达标（低于 87.5%） 35%
0.875 < Q < 1.125 达标区间 实际比例
Q ≥ 1.125 超额完成（≥112.5%） 45%
共享伙伴兑现条件矩阵
前提：P > 0 且现金流为正，按实际回款比例发放奖金；次年 Q2 起每季度核算。

公司管理费 OH 标准
OH 直接从 R 中扣除，影响利润贡献值 P 的大小。EPC 类管理费率显著低于设计咨询类。
否决项 / 减分项
  • 否
    一票否决
    三级以上质量或安全事故、道德事件、合规事件
  • 扣
    发票红冲
    等额损失（含税）从共享伙伴奖金中等额扣除
  • 扣
    坏账处理
    全额计入成本，并按坏账额度分级扣除奖金

共享伙伴岗位工资发放四种情形
情形 A：盈利 + 现金流为正

P > 0，次年 Q1 现金流 > 0
规则：全额发放岗位工资

示例：年工资 144 万 → 实发 144 万

情形 B：盈利 + 现金流为负（缓发）

P > 0，次年 Q1 现金流 ≤ 0
规则：缓发，待现金流转正后补发

示例：年工资 120 万，Q1 实发 0；Q2 转正后补发 120 万

情形 C：亏损 + 现金流为正（按比例）

P < 0，次年 Q1 现金流 > 0
规则：工资 = 工资总额 + P × 40%

示例：年工资 60 万，亏损 50 万 → 实发 40 万（扣 20 万）

情形 D：亏损 + 现金流为负（缓发+扣减）

P < 0，次年 Q1 现金流 ≤ 0
规则：按比例缓发，转正后补发

示例：年工资 36 万，亏损 16 万 → Q1 实发 0；Q2 补发 29.6 万

四、成本中心考核（专业室）
核算公式
内部收入 N
N = ∑ (R1 × MH × (1 + Y%))
R1：工程师费率｜MH：确认工时｜Y%：奖金系数
实际成本 C
C = ∑ 工程师个人成本 C1
可分配奖金 B
B = N − C
B > 0 可分配；B < 0 室主任无奖金；个人盈利仍受保护
工时改革：取消 49 小时/周上限，所有确认工时计入项目成本，提升资源成本真实性。
